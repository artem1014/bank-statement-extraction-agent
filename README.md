# Bank Statement Extraction Agent

Агент для извлечения данных из банковских выписок.

## Описание

Проект автоматизирует разбор банковских выписок (PDF/изображения/CSV) и извлекает структурированные данные о транзакциях.

## Установка

```bash
git clone https://github.com/<user>/bank-statement-extraction-agent.git
cd bank-statement-extraction-agent
```
